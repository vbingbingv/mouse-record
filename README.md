# 鼠标录制与回放工具（Mouse Record）

把鼠标的移动、点击、滚轮按原时序录下来，之后按原来的节奏重复回放。适合处理重复性的鼠标操作。

- 平台：Windows 10 / 11（x64），不支持其它系统
- 许可：MIT

## 安装

1. 打开 [Releases](https://github.com/vbingbingv/mouse-record/releases) 下载 `mouse-record_0.1.0_x64-setup.exe`。
2. 双击安装（安装界面可选简体中文 / English），完成后从开始菜单启动。

如果 Release 里还没有安装包，可以在 [Actions](https://github.com/vbingbingv/mouse-record/actions) 里打开最近一次成功的 `Build (Windows NSIS)` 运行，下载 `mouse-record-nsis-x64-<运行编号>` 产物，解压后得到同一个安装包。

> 安装包目前没有数字签名，首次运行会看到蓝色的「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可。程序每次启动都会请求管理员权限，UAC 里显示「未知发布者」也是同一个原因。

## 快速上手

启动时先允许 UAC 授权，否则录不到鼠标事件。

1. **录制**：点「开始录制」，或按全局热键 `Ctrl+8`。窗口会自动隐藏，正常操作鼠标即可；结束时再按一次 `Ctrl+8`。
2. **回放**：点「开始回放」，或按 `Ctrl+9`。窗口同样自动隐藏，回放结束后自动恢复。
3. **保存复用**：在「录制库」里输入名称 → 「保存当前录制」；之后点「加载」把它取回来再回放。

「录制」面板会实时显示动作数量、录制时长和当前鼠标坐标。

关于热键：

- 只有 `Ctrl+8`（录制）、`Ctrl+9`（回放）两个，必须先按住 `Ctrl` 再按数字键，按住不放不会重复触发。
- 录制中按 `Ctrl+8`、回放中按 `Ctrl+9` 为停止；交叉按（录制中按 `Ctrl+9` 等）不做任何事，避免误操作。
- 热键只在程序运行时有效；窗口隐藏期间也只能用热键停止，所以请记住对应的按键。

## 回放参数

在「回放」面板里设置，**必须在开始前设好**——回放期间窗口是隐藏的，改不了：

- 循环次数：1 ~ 100000
- 循环间隔：两轮之间的等待时间，默认 500 ms
- 速度：0.5x / 1.0x / 2.0x / 5.0x
- 无限循环：勾选后一直循环，直到按 `Ctrl+9`
- 用 `Ctrl+9` 触发的回放会沿用界面上的这套参数

回放中面板会显示「第 N/M 轮 · 动作 i/k」的进度。

## 录制文件位置

保存的录制是 JSON 文件，存放于：

```text
%APPDATA%\com.mouserecord.app\recordings\<名称>.json
```

名称只能用字母、数字、空格、`-`、`_`、`.`，最长 100 个字符；直接删掉文件夹里的 JSON 等效于界面上的「删除」。

## 能录什么、不能录什么

- 能录：鼠标移动、左/中/右键的按下与抬起、滚轮（含横向滚动）、每次动作之间的时间间隔；多显示器的坐标也能正确回放。
- 不录：键盘输入，键盘只用于 `Ctrl+8` / `Ctrl+9` 两个热键。
- 录制和回放不能同时进行。

## 常见问题

**回放的时候我还能自己动鼠标吗？**
不建议。回放会用程序模拟的鼠标事件接管指针，手动移动会和它打架。想停下来按 `Ctrl+9`。

**按了热键没反应？**
检查这几点：程序是否还在运行（热键只在运行期间有效）；状态栏是否提示输入监听不可用（全局钩子没装上，重启程序并以管理员身份运行）；是不是交叉按了（录制中按 `Ctrl+9`、回放中按 `Ctrl+8` 本来就无效）。

**窗口不见了 / 想点「停止」按钮但找不到窗口？**
录制和回放期间窗口是故意隐藏的，避免挡住你要操作的目标程序，结束后会自动显示；隐藏期间只能用热键停止（录制 `Ctrl+8`、回放 `Ctrl+9`）。

**`ESC` 能停止回放吗？**
不能，`ESC` 不再是停止键，请用 `Ctrl+9` 或界面上的「停止回放」。

**回放一直停不下来？**
大概率是勾了「无限循环」，按 `Ctrl+9` 停止即可。
