# 鼠标录制与回放工具（Mouse Record）

把鼠标的移动、点击、滚轮按原时序录下来，之后按原来的节奏重复回放。适合处理重复性的鼠标操作。

- 平台：Windows 10 / 11（x64）、macOS 10.15 及以上（Intel / Apple 芯片）
- 许可：MIT

## 安装

### Windows

1. 打开 [Releases](https://github.com/vbingbingv/mouse-record/releases) 下载 `mouse-record_0.1.0_x64-setup.exe`。
2. 双击安装（安装界面可选简体中文 / English），完成后从开始菜单启动。

如果 Release 里还没有安装包，可以在 [Actions](https://github.com/vbingbingv/mouse-record/actions) 里打开最近一次成功的 `Build (Windows NSIS)` 运行，下载 `mouse-record-nsis-x64-<运行编号>` 产物，解压后得到同一个安装包。

> 安装包目前没有数字签名，首次运行会看到蓝色的「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可。程序每次启动都会请求管理员权限，UAC 里显示「未知发布者」也是同一个原因。

### macOS

1. 本地构建：`npm install && npm run tauri build`，产物为
   `src-tauri/target/release/bundle/macos/mouse-record.app` 与同目录下的 `dmg/`。
2. 打开 dmg，把 mouse-record 拖进「应用程序」。
3. 首次启动如果提示「无法验证开发者」，到 系统设置 → 隐私与安全性 点「仍要打开」。
4. 首次启动会申请两项权限，**都打开后重启本应用**（macOS 要让新权限对进程生效，重启最稳）：

   | 权限 | 用途 | 授权位置 |
   | --- | --- | --- |
   | 输入监控 | 录制鼠标、全局快捷键 `Control+8` / `Control+9` | 系统设置 → 隐私与安全性 → 输入监控 |
   | 辅助功能 | 回放鼠标操作（合成鼠标事件） | 系统设置 → 隐私与安全性 → 辅助功能 |

   界面顶部会列出还缺哪一项，点「去开启」直接跳到对应面板，回来后点「重新检测」。

> macOS 与 Windows 的对应关系：Windows 靠启动时的 UAC 提权，macOS 靠上面这两项系统授权。没授权时录制/回放会静默失败，因此界面上会明确提示。

## 快速上手

启动时先允许 UAC 授权（Windows）或打开两项系统授权（macOS，见上），否则录不到鼠标事件。

1. **录制**：点「开始录制」，或按全局热键 `Ctrl+8`。窗口会自动隐藏，正常操作鼠标即可；结束时再按一次 `Ctrl+8`。
2. **回放**：点「开始回放」，或按 `Ctrl+9`。窗口同样自动隐藏，回放结束后自动恢复。
3. **保存复用**：在「录制库」里输入名称 → 「保存当前录制」；之后点「加载」把它取回来再回放。

「录制」面板会实时显示动作数量、录制时长和当前鼠标坐标。

关于热键：

- 只有 `Ctrl+8`（录制）、`Ctrl+9`（回放）两个，必须先按住 `Ctrl` 再按数字键，按住不放不会重复触发。
- macOS 上修饰键是键盘左下角的 `Control`，不是 `Command`，与 Windows 保持一致。
- 录制中按 `Ctrl+8`、回放中按 `Ctrl+9` 为停止；交叉按（录制中按 `Ctrl+9` 等）不做任何事，避免误操作。
- 热键只在程序运行时有效；窗口隐藏期间也只能用热键停止，所以请记住对应的按键。

## 回放参数

在「回放」面板里设置，**必须在开始前设好**——回放期间窗口是隐藏的，改不了：

- 循环次数：1 ~ 100000
- 循环间隔：两轮之间的等待时间，默认 500 ms
- 速度：0.5x / 1.0x / 2.0x / 5.0x
- 无限循环：勾选后一直循环，直到按 `Ctrl+9`
- 用 `Ctrl+9` 触发的回放会沿用界面上的这套参数

回放中面板会显示「第 N/M 轮 · 动作 i/k」的进度。

## 录制文件位置

保存的录制是 JSON 文件，存放于：

```text
Windows: %APPDATA%\com.mouserecord.app\recordings\<名称>.json
macOS:   ~/Library/Application Support/com.mouserecord.app/recordings/<名称>.json
```

名称只能用字母、数字、空格、`-`、`_`、`.`，最长 100 个字符；直接删掉文件夹里的 JSON 等效于界面上的「删除」。

## 能录什么、不能录什么

- 能录：鼠标移动、左/中/右键的按下与抬起、滚轮（含横向滚动）、每次动作之间的时间间隔；多显示器的坐标也能正确回放。
- 不录：键盘输入，键盘只用于 `Ctrl+8` / `Ctrl+9` 两个热键。
- 录制和回放不能同时进行。
- 录制文件在两个平台之间通用（滚轮精度在 macOS 上是像素级，Windows 上是滚轮格）。

## 常见问题

**回放的时候我还能自己动鼠标吗？**
不建议。回放会用程序模拟的鼠标事件接管指针，手动移动会和它打架。想停下来按 `Ctrl+9`。

**按了热键没反应？**
检查这几点：程序是否还在运行（热键只在运行期间有效）；界面顶部是否提示缺少系统授权（Windows 需要以管理员身份运行，macOS 需要「输入监控」权限，授权后重启程序）；是不是交叉按了（录制中按 `Ctrl+9`、回放中按 `Ctrl+8` 本来就无效）。

**macOS 上给了权限还是不行？**
区分两项权限，缺哪项坏哪项：

| 缺的权限 | 表现 |
| --- | --- |
| 输入监控 | 录制录不到任何东西，`Control+8` / `Control+9` **完全没反应**（键盘事件被系统丢掉） |
| 辅助功能 | 回放时鼠标不动（合成事件被丢掉） |

排查步骤：

1. 界面顶部会逐项显示「已授权 / 未授权」和「上次检测」时间，先看哪一项是未授权。
2. 点该项的「去开启」跳到系统设置（输入监控在 系统设置 → 隐私与安全性 → 输入监控 / 辅助功能）并打开开关。
3. 回到应用点「重启应用」——macOS 的授权对已运行进程有缓存，重启进程才会真正生效。不重启的话后台每 5 秒重试一次，也可能自动恢复。
4. 列表里没有 mouse-record：点「申请授权」触发系统弹窗后它才会出现。
5. 重新构建过应用（签名变化）后权限可能对不上旧条目：在系统设置里用「−」删掉旧条目，重启应用重新授权一次。

录制/回放期间窗口会隐藏（避免挡住目标程序），此时**点 Dock 里的图标就能把窗口找回来**（比如热键不灵、想点「停止录制」按钮）。如果输入监听本身不可用，程序不会隐藏窗口，避免既录不到又停不下来。

**macOS 上点了「开始回放」但鼠标不动？**
回放需要「辅助功能」授权（合成鼠标事件），录制需要「输入监控」授权（监听全局输入），两者都在 系统设置 → 隐私与安全性 里，授权后重启本应用。

**首次使用 macOS 版需要注意什么？**
用本地构建的 `mouse-record.app`（或安装到「应用程序」）运行；每次重新构建（`npm run tauri build`）都会生成新的应用签名，系统可能要求你重新授权一次，这时在 系统设置 → 隐私与安全性 里把旧的 mouse-record 条目删掉再重新添加即可。

**窗口不见了 / 想点「停止」按钮但找不到窗口？**
录制和回放期间窗口是故意隐藏的，避免挡住你要操作的目标程序，结束后会自动显示；隐藏期间只能用热键停止（录制 `Ctrl+8`、回放 `Ctrl+9`）。

**`ESC` 能停止回放吗？**
不能，`ESC` 不再是停止键，请用 `Ctrl+9` 或界面上的「停止回放」。

**回放一直停不下来？**
大概率是勾了「无限循环」，按 `Ctrl+9` 停止即可。
